# Smart Farm Dashboard  
A comprehensive dashboard for smart agriculture management, supporting farmers, managers, and administrators with real-time monitoring, irrigation control, supply chain tracking, and data analytics.  


## 🌟 Features  
- **Multi-Role Support**: Switch between *Farmer*, *Manager*, and *Administrator* roles.  
- **Real-Time Monitoring**: Sensor data (moisture, temperature, humidity) and weather alerts.  
- **Smart Irrigation**: Automated/Manual control of irrigation zones.  
- **Supply Chain Management**: Logistics tracking, inventory, and order management.  
- **Data Analytics**: Performance reports, yield trends, and resource usage analysis.  
- **Responsive Design**: Works on desktop, tablet, and mobile devices.
